# Security policy

Report suspected vulnerabilities privately to [yassine@yaschet.com](mailto:yassine@yaschet.com). Include the affected code path, impact and a minimal reproduction using synthetic data. Do not publish credentials, customer documents or exploit details in an issue.

If GitHub private vulnerability reporting is available, you may use the repository's Security tab. Email remains available independently of repository features.

Only the current release receives security maintenance. This repository includes service adapters; operators are responsible for their account permissions, database policies, secret handling and provider updates. The offline suite does not certify a production deployment.
